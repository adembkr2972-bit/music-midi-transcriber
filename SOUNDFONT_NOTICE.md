# SoundFont notice

The app can download **GeneralUser GS 1.471** by S. Christian Collins for local MIDI-to-audio previews. The SoundFont is not included in this repository; it is downloaded to the user's local application data directory on first use and reused from that cache.

Project page and license: <https://github.com/planet-s/generaluser-gs>

The SoundFont is provided by its author under the license published in that project. Review the current license and the author's notes before redistributing the SoundFont or using it in a product. The app only caches it locally for rendering. Users can instead upload a compatible `.sf2` SoundFont they are permitted to use.
